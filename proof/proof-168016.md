# BB(6) holdout #168016 — formula-tape proof draft (Phase 3, 2026-11-24)

- Seed index: **168016**
- Spec: `1RB1RA_1RC1LB_0LD0RA_1RF1LE_---1LF_1LC0LF`
- Transition table:

  | state | on 0 | on 1 |
  |---|---|---|
  | A | 1RB | 1RA |
  | B | 1RC | 1LB |
  | C | 0LD | 0RA |
  | D | 1RF | 1LE |
  | E | **— (halt)** | 1LF |
  | F | 1LC | 0LF |

  The only undefined transition is **E on 0**: the machine halts iff it
  ever is in state E reading a 0.

## Headline outcome of this phase (read first)

The bouncer induction **does not go through for all k**. The step
S(k) → S(k+2) holds, with an exact closed-form step count, for every
even k from 2 to 54 — but it **fails at k = 56**: from S(56) the
machine never reaches S(58); near the end of that period the head
writes 4 cells beyond the left edge of the pattern and the machine
leaves the bounce family. The real (blank-tape) trajectory confirms
this: it reaches S(56) and then no further S(k), with no halt in
4×10^10 steps. So #168016 is **not** decided by the bouncer argument.
Sections A–B give what *is* rigorously established; Section C gives
the k = 56 counterexample in detail; Section D lists what remains.

This file also corrects three errors in `candidate-168016.md`:
the wall L has **51 cells, not 49**; the bounce family in the real
trajectory starts at **k = 2, not k = 30** (and sits at absolute
offset −12); the step labels quoted there are 0-based recorder
labels (transitions executed = label + 1; all *periods* agree).

## Definitions (translation-invariant)

Positions are relative to the pattern's left edge. A configuration
is specified up to translation: the tape is blank outside the stated
word.

- Wall: `L = 1^4 0 1^17 0 1^27 0` (51 cells, 48 ones), i.e.
  `111101111111111111111101111111111111111111111111110`.
- **S(k)** (even k ≥ 2): tape `L · 1^k · 0`, head on the final 0
  (relative position 51 + k), state B.
- **X(k)**: tape `L · 1^(k+1)`, head at relative position k + 50
  (one cell left of the rightmost 1), state E.
- **Y(k)**: tape `L[:49] · "01" · 1^(k+1)` over relative positions
  [0, 51 + k] — i.e. L with its last two cells `10` (positions 49, 50)
  flipped to `01`, so the 1-run beginning at position 50 has length
  k + 2 — head at relative position k + 50, state B.

Step counts below are **transitions executed**.

## B. The induction step as shift rules (phase decomposition)

For every even k in the verified range, one period decomposes into
three consecutive phases (`phases2.py`, `phase168016.c`,
`phase3.py`):

    S(k) --phase 1--> X(k) --phase 2--> Y(k) --phase 3--> S(k+2)
    costs:    3        ph2(k)          2k + 5

with ph2(k) = 3·2^((k+4)/2) − 2k − 14 (so the three costs sum to
P(k)). Phases 1 and 3 are proven below for **all** k; phase 2 is the
entire difficulty and is where k = 56 fails.

### Phase 1: S(k) → X(k) in 3 steps — proven for all k

From S(k) (head on the final 0, state B):
1. B on 0 → `1RC`: writes 1 (block now has k+1 ones), head moves
   right onto a fresh 0, state C.
2. C on 0 → `0LD`: writes 0, head moves left onto the 1 just
   written, state D.
3. D on 1 → `1LE`: writes 1, head moves left, state E.
Result: tape `L · 1^(k+1)`, head one cell left of the rightmost 1,
state E — exactly X(k). Purely local; no side conditions. ∎

### Phase 3: Y(k) → S(k+2) in 2k + 5 steps — proven for all k

From Y(k) (position 49 is 0; positions 50…51+k are 1; blank beyond;
head at k + 50, state B):
1. **B-sweep** (k+1 steps): B on 1 → `1LB` repeated. The head walks
   left across the 1-run from position k + 50 down to position 49.
   (Uniform rule on 1; the run's left end is marked by the 0 at
   position 49.)
2. **Repair** (1 step): B on 0 → `1RC` at position 49: restores
   L's cell 49 to 1, head to 50, state C.
3. **Repair** (1 step): C on 1 → `0RA` at position 50: restores
   L's cell 50 to 0, head to 51, state A.
4. **A-sweep** (k+1 steps): A on 1 → `1RA` repeated. The head walks
   right across positions 51…51+k.
5. **Extension** (1 step): A on 0 → `1RB` at position 51+k+1
   (blank in Y(k)): writes the (k+2)-th block 1, head to 52+k+… =
   relative position 51 + (k+2), state B.
Result: tape `L · 1^(k+2) · 0`, head on the final 0, state B —
exactly S(k+2). Each sweep is a finite run of a single uniform
transition over a 1-run terminated by a 0 (resp. by the blank cell
the sweep itself must reach), so the argument is a routine
induction on the run length; the head never leaves [49, 52 + k],
so the rest of the tape is untouched. Total
(k+1) + 1 + 1 + (k+1) + 1 = 2k + 5. ∎
(Traces for k = 16, 20 recorded by `phase3.py` match this rule
sequence step for step.)

### Phase 2: X(k) → Y(k) — empirical only; NOT proven

Measured (`phases2.py` for k = 16…28, `phase168016.c` for k = 54):
- cost ph2(k) = 3·2^((k+4)/2) − 2k − 14; equivalently
  ph2(k+2) = 2·ph2(k) + 2k + 10 — the doubling indicates a
  self-similar internal structure, but **no explicit shift-rule
  decomposition of phase 2 has been extracted yet**; in
  particular the intermediate configuration that would split
  phase 2 into two half-size copies is unidentified.
- During phase 2 (for k ≤ 54) the head stays within relative
  positions [50 − k/2, 51 + k]; the wall's left part is never
  reached. The net effect is exactly the flip of the wall's last
  two cells `10 → 01` with the tape otherwise unchanged and the
  head returned to position k + 50 in state B instead of E.
- Any community-grade proof must prove phase 2 for all k
  (formula-tape shift rules, or a Rocq/Lean formalisation in the
  busycoq style). Section C shows that **as stated, phase 2 is
  false for k = 56**, so such a proof cannot exist without an
  additional hypothesis that already fails at k = 56.

## C. The k = 56 counterexample (detail)

From S(56) (synthetic start, relative frame; `phase168016.c`,
`probe168016.c`):
- Phase 1 completes: X(56) is reached at period-step 3.
- The formula predictions would be Y(56) at period-step
  3,221,225,343 and S(58) at 3,221,225,466. **Neither occurs.**
- At period-step **3,221,223,994** (1,349 steps before the
  predicted Y(56)) the head first crosses to relative position
  −1, i.e. it writes **outside the pattern's left edge**; it
  reaches relative position −4.
- At period-step **3,221,226,692** (= P(56) + 1,226) the first
  right-edge record in state B fires, with head at relative
  position 109 and tape (relative span [−4, 109]) of run-length
  form

      1^4 0 1^42 0 1^65 0        (111 ones, 114 cells)

  This is **not** of the form L · 1^m · 0 under any translation
  (checked exhaustively for m ≤ 220 and shifts −8…+8): the wall's
  internal separators have moved (compare L = 1^4 0 1^17 0 1^27 0).
- At the exact predicted step P(56) the configuration is entirely
  different (state A, head at relative position 71, tape already
  showing (011)-periodic regions on the right).

Consistent with A.1: the real trajectory reaches S(56) and then
leaves the family permanently (no S(58) in 3.7×10^10 further
steps, no halt). Synthetic starts from S(58) and S(60) — clean
configurations the real trajectory never reaches — also do not
halt; their first state-B right-edge records occur at
28,991,030,218 and 28,991,030,242 steps respectively, again with
non-S tapes. (The near-identical counts suggest both runs merge
into a common post-break evolution, differing by a 24-step phase
offset; not analysed further here.)

**Conclusion.** The bounce family of #168016 is finite: it runs
from k = 2 to k = 56 and then breaks. The bouncer argument
therefore does **not** decide #168016. The machine is still
undecided — with strong evidence of non-halting (no halt in
4×10^10 steps) but no proof: after absolute step ≈ 6.44×10^9 it
evolves in a post-break regime that has not been characterised.

## D. What remains before a forum post would be credible

1. **Characterise the post-break regime.** Starting from the
   configuration at/after the k = 56 breach (relative span
   [−4, 109], RLE above), find the machine's new long-term
   behaviour: a new formula-tape family (different wall/block),
   a counter-like rule system, a translated cycler, or something
   else. Only then can a non-halting proof be attempted again.
   (If instead the post-break regime ever reaches E on 0, the
   machine would halt — nothing in the current data suggests
   this, but the family break means it can no longer be excluded
   by the bouncer pattern alone.)
2. **If a new family is found**, redo this programme for it:
   exact finite verification across a wide parameter range
   (including isolated synthetic starts, not just the composed
   trajectory), an explicit shift-rule decomposition of every
   phase, and a proof of each phase for all parameter values —
   ideally machine-checked (Rocq/busycoq or Lean), matching the
   standard of the November 2026 holdout proofs on the wiki.
   The k = 56 failure is the cautionary tale: a pattern verified
   for 27 consecutive cases still failed at the 28th.
3. **Community status** (checked 2026-11-24; see research notes
   in the Phase 3 report): no public record that #168016 has been
   decided — the newest public holdout list is still the
   608-machine list of 2026-10-30 containing it, and the machine
   has no wiki page. Caveat: the community's annotated
   spreadsheet and Discord are not publicly checkable for a
   specific machine, so a Discord-only claim after 2026-10-30
   cannot be excluded from public sources. This matters only
   once a proof exists; nothing is ready to post now.
