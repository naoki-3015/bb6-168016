## 3. The β proviso: reduced (Phase 16), then resolved — negatively (Phase 17)

Phase 15 left one global hypothesis: **β ≥ 3 at C-form
right-sections**. Phase 16 attacks it with the *C-phase law*,
a consequence of the five mirror rules (recorded in
`phase16_beta.py`'s docstring): group consecutive C-sections
into phases (a phase = a maximal run of C-sections, of length
1 or 2). Writing β_C0 for β at a phase's first section:

- **(law a)** every B-section has g1 = 1 and r1 ≥ 4; every
  C-section has r1 = 2 (invariant RI restated);
- **(law b)** a phase of length 2 has second section with
  g1 = 1 and β = β_C0 − 1; post-entry, phases start with
  g1 ≥ 3, hence fire RPUSH, hence have length exactly 2;
- **(law c)** phases strictly alternate: a phase starting
  with g1 ≥ 5 (**type A**) forces the next phase to start
  with g1 = 3 (**type B**), and a type-B phase forces the
  next start to have g1 ≥ 5;
- **(law d)** with Δ = β_C0 − β(first B-section after the
  phase) ∈ {2, 3} and ρ = β(next phase start) − β(first B
  after the phase) − 2: type A ⟹ ρ = 0 and β(next start) =
  β_C0 − 1 (β_C0 **decreases by exactly 1**); type B ⟹
  ρ ≥ 1 and β(next start) = β_C0 − 1 + ρ (**no decrease**).
